# 프로젝트: 월마감 체크리스트 자동화 도구

마감 자료 여러 개를 읽어 월마감 점검 리포트를 만드는 도구.

## 작업 규칙

- 데이터는 data/ 폴더의 CSV를 읽는다. 파이썬 설치가 필요한 작업은 하지 않는다.
- 합계와 차이는 파일 내용을 직접 읽어서 계산한다. awk·sed 같은 터미널 명령으로 처리하지 않는다. 윈도우 노트북에는 그 명령들이 없다.
- 원본 데이터 파일은 수정하지 않는다. 산출물은 프로젝트 최상위에만 만든다.
- 금액은 원본에 적힌 값을 그대로 쓴다. 원본에 없는 숫자는 추정하지 않고 "확인 불가"로 적는다.
- 분개 자동 생성, 회계시스템 연결, 세무 판단은 만들지 않는다.
